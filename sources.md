# Sources and maintenance notes

References checked when preparing the workbook on November 1, 2026. These sources explain Census concepts; they do not endorse this workbook or supply data for the fictional worked case.

| Source | Used for |
| --- | --- |
| [Census C16001 metadata, 2024 ACS five-year](https://api.census.gov/data/2024/acs/acs5/groups/C16001.html) | The age-five-and-over universe, original language-group labels, and separate estimate/margin fields. Choose metadata matching the release you actually use. |
| [Census ZIP Code Tabulation Areas](https://www.census.gov/programs-surveys/geography/guidance/geo-areas/zctas.html) | ZCTAs approximate geographic distributions of postal codes; they are not postal routes and do not represent every valid ZIP code. |
| [Census guidance on ACS margins when comparing estimates](https://www.census.gov/help/topics/faq.do-i-need-to-consider-the-margins-of-error-when-comparing-acs-estimates.html) | Sampling uncertainty must be considered before interpreting a difference. |
| [Census 2020–2024 ACS accuracy guidance](https://www2.census.gov/programs-surveys/acs/tech_docs/accuracy/MultiyearACSAccuracyofData2024.pdf) | Published margin-of-error conventions and methodological limits. The workbook does not implement its statistical calculations. |
| [Census guidance on ACS estimate periods](https://www.census.gov/programs-surveys/acs/guidance/estimates.html) | Distinguishing one-year and multiyear estimate periods. |

The listening prompts, private tally and decision workflow are original proposals, not Census questions or a validated survey. The sources support the statistical and geographic cautions; they do not establish that the proposed workflow improves outcomes.

When updating the workbook, preserve the source URL, date checked and the claim it supports. Check changed table labels, geography definitions and release periods before updating examples. Never replace the fictional case with real participant data in a public contribution. Suggest corrections using a small non-sensitive example; do not upload completed private workbooks.
